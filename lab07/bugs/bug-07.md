# BUG-07: «Он» талбарт 1000-2100-аас гадуурх, бутархай, үсэг бүхий утга шалгалтгүйгээр хадгалагдана

**Орчин:** Уншлагын жагсаалт v2.0, Chromium 152.0.7977.149 (Claude desktop built-in browser), macOS 26.6.2, node v20.20.2, 2026-10-17
**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном), браузерт http://localhost:3000 нээсэн

## Дахин гаргах алхам

1. Гарчиг = `Ирээдүйн ном`, Зохиолч = `Тестер`, Он = `2500` гэж бичээд «Нэмэx» дарна.
2. Гарчиг талбарын бичвэрийг бүгдийг сонгож `Үсэгтэй он` болгож, Он талбарын бичвэрийг бүгдийг сонгож `abc` болгоод «Нэмэx» дарна (Зохиолч `Тестер` хэвээр).
3. Хүснэгт болон «Хамгийн шинэ он» текстийг харна.
4. (API) `curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title":"Test 1","author":"X","year":999}'` (мөн `2101`, `"abc"`, `1999.5`)

**Хүлээгдэж байсан:** Спецификаци — «Он нь 1000-2100 хоорондох бүхэл тоо». Буруу он бүхий ном нэмэгдэхгүй, ойлгомжтой алдааны мессеж гарна; API 400 буцаана.

**Бодит үр дүн:** Хоёр ном хоёулаа «Ном нэмэгдлээ» мессежтэй нэмэгдэв: «Ирээдүйн ном … 2,500», «Үсэгтэй он … NaN». Доор «Хамгийн шинэ он: 2500» гэж буруу статистик гарна. API-аар 999, 2101, "abc", 1999.5 бүгд `HTTP/1.1 201 Created` (evidence/bug-07-curl.txt).

**Ноцтой байдал:** Major — буруу өгөгдөл хадгалагдаж, «Хамгийн шинэ он» зэрэг тооцоолсон утгыг эвдэнэ; хүснэгтэд «NaN» харагдана.
