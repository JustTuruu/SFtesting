# BUG-03: Аюултай үйлдлийн «Устгах» товч улаан биш, ногоон өнгөтэй

**Орчин:** Уншлагын жагсаалт v2.0, Chromium 152.0.7977.149 (Claude desktop built-in browser), macOS 26.6.2, node v20.20.2, 2026-10-17
**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном), браузерт http://localhost:3000 нээсэн

## Дахин гаргах алхам

1. http://localhost:3000 хуудсыг нээнэ.
2. Хүснэгтийн мөр бүрийн баруун талын «Устгах» товчны өнгийг харна.

**Хүлээгдэж байсан:** Спецификаци — «Аюултай үйлдлийн товч (Устгах) улаан өнгөтэй».

**Бодит үр дүн:** Бүх «Устгах» товч ногоон дэвсгэртэй, цагаан бичигтэй. Ногоон өнгө нь «зөвшөөрөх/аюулгүй» үйлдлийг илэрхийлдэг тул хэрэглэгч санамсаргүй устгах эрсдэлтэй (мөн устгахын өмнө баталгаажуулах асуулт гарахгүй).

**Ноцтой байдал:** Minor — функц ажиллана, гэхдээ UX-ийн тогтсон дүрэм ба спецификацийг зөрчиж, санамсаргүй өгөгдөл устгах магадлалыг нэмэгдүүлнэ.
