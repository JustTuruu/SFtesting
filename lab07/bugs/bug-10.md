# BUG-10: Хуудасны доорх «Хуучин хувилбар» линк 500 Internal Server Error буцаана

**Орчин:** Уншлагын жагсаалт v2.0, Chromium 152.0.7977.149 (Claude desktop built-in browser), macOS 26.6.2, node v20.20.2, 2026-10-17
**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном), браузерт http://localhost:3000 нээсэн

## Дахин гаргах алхам

1. Хуудасны доод хэсгийн «Хуучин хувилбар» линк дээр дарна.
2. (API) `curl -i localhost:3000/old`

**Хүлээгдэж байсан:** Спецификаци — «бүх хуудас, линк ажиллана» → хуучин хувилбарын хуудас нээгдэнэ.

**Бодит үр дүн:** Браузерт хар дэвсгэр дээр зөвхөн «Internal Server Error» текст. curl: `HTTP/1.1 500 Internal Server Error`. Буцах линк ч байхгүй.

**Ноцтой байдал:** Major — хэрэглэгчид харагдаж буй линк серверийн алдаа үүсгэнэ (хуудас бүхэлдээ ажиллахгүй).
