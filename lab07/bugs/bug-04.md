# BUG-04: «Нэмэx» товчны сүүлийн үсэг кирилл «х» биш, латин «x»

**Орчин:** Уншлагын жагсаалт v2.0, Chromium 152.0.7977.149 (Claude desktop built-in browser), macOS 26.6.2, node v20.20.2, 2026-10-17
**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном), браузерт http://localhost:3000 нээсэн

## Дахин гаргах алхам

1. Терминалд дараахыг ажиллуулна:
   ```bash
   curl -s localhost:3000/ | grep -o 'Нэмэ.' | od -c
   ```
2. Гаралтын сүүлийн тэмдэгтийг харна.
3. (Браузерт) http://localhost:3000 дээр Ctrl+F / Cmd+F дарж кирилл үсгээр «Нэмэх» гэж хайна.

**Хүлээгдэж байсан:** Спецификаци — «текстүүд үсгийн алдаагүй». Товчны бичвэр бүхэлдээ кирилл «Нэмэх» (сүүлийн үсэг UTF-8 байт `321 205`).

**Бодит үр дүн:** `320 235 321 215 320 274 321 215   x` — эхний 4 үсэг кирилл, сүүлийнх нь ASCII латин `x` (0x78). Браузерын хуудсан доторх хайлтаар «Нэмэх» олдохгүй. Нүдээр ялгагдахгүй ч screen reader, автомат тест (`getByText('Нэмэх')`), хайлт бүгд энэ товчийг олохгүй.

**Ноцтой байдал:** Cosmetic — харагдах байдалд нөлөөгүй, гэхдээ хүртээмж (accessibility) ба автомат тестэд саад болно.
