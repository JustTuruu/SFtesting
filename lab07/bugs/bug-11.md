# BUG-11: POST /api/books буруу JSON биетэй хүсэлтэд 400 биш «200 OK {"result":"OK"}» буцаана

**Орчин:** Уншлагын жагсаалт v2.0, curl 8.7.1, macOS 26.6.2, node v20.20.2, 2026-10-17
**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Терминалд:
   ```bash
   curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d 'буруу оролт'
   ```
2. Дутуу (таслагдсан) JSON илгээнэ:
   ```bash
   curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title":"A","author":"B","year":'
   ```
3. `curl -i localhost:3000/api/books` — жагсаалтыг шалгана.

**Хүлээгдэж байсан:** Спецификаци — «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана» → `HTTP/1.1 400 Bad Request` ба алдааны тайлбар.

**Бодит үр дүн:** 1 ба 2-р алхам хоёулаа `HTTP/1.1 200 OK`, бие нь `{"result":"OK"}`. 3-р алхамд жагсаалт өөрчлөгдөөгүй (3 ном) — өөрөөр хэлбэл сервер хүсэлтийг чимээгүй хаяж, клиентэд «амжилттай» гэж худал хэлж байна. (Зөв JSON нэмэхэд `201 Created` + `id` буцдаг тул 200 нь ч тогтворгүй.)

**Ноцтой байдал:** Major — API-ийн клиент (мобайл апп, интеграц) алдааг илрүүлэх боломжгүй, өгөгдөл чимээгүй алдагдана.
