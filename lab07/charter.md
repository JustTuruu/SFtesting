# Charter

**Судлах:** «Уншлагын жагсаалт» v2.0 вэб апп (http://localhost:3000) — ном нэмэх форм (Гарчиг, Зохиолч, Он), номын хүснэгт ба «Нийт ном» тоолуур, хайлт, устгах үйлдэл, үйлдлийн дараах мессежүүд, хуудас/линкүүд болон `/api/books` REST API.

**Ашиглан:** Хоосон ба зөвхөн зайтай оролт, хилийн утгууд (999, 1000, 2100, 2101, бутархай, сөрөг, үсэг), маш урт текст, тусгай тэмдэгт/HTML (`<b>`, `<script>`), кирилл ба том/жижиг үсгийн хослол, давхардсан ном; браузерын Chromium болон `curl -i` (буруу JSON, хоосон бие, буруу Content-Type, байхгүй id).

**Илрүүлэх:** Спецификацийн дүрэм зөрчсөн согог — баталгаажуулалт (validation) алгасах, давхардал, хайлтын том/жижиг үсэг, буруу/үсгийн алдаатай мессеж, тоолуурын зөрүү, хүснэгт эвдрэх, Устгах товчны өнгө, ажиллахгүй линк, API-ийн буруу статус код (400-ийн оронд 500/200) ба өгөгдлийн бүрэн бүтэн байдлын алдаа.

## Сонгосон аялалууд (2-оос доошгүй, өөр өөр дүүргээс)

- **Supermodel (Tourist district, GUI)** — апп нь нэг хуудастай, өнгө, текст, мессеж, товчны харагдах байдал спецификацид шууд заагдсан тул гадаргуугийн согогийг (үсгийн алдаа, Устгах товчны өнгө, хүснэгтийн байршил) олоход хамгийн тохиромжтой.
- **Couch Potato (Hotel district, хоосон оролт)** — «гурван талбар заавал» гэсэн дүрэм байгаа тул талбаруудыг хоосон/зайтай үлдээж, хамгийн бага хүчин чармайлтаар апп юу хийхийг шалгана.
- **Saboteur (Seedy district, API довтолгоо)** — UI-ийн шалгалтыг тойрч `curl`-ээр буруу JSON, дутуу талбар, буруу он илгээвэл сервер өөрөө шалгаж байгаа эсэх, 400 буцаах эсэхийг шалгана.
- **Antisocial (Seedy district, санаатай буруу оролт)** — Он талбарт үсэг/бутархай/хилээс гадуурх утга, маш урт гарчиг, HTML тэмдэгт оруулж, апп «хүлээгдээгүй» оролтыг хэрхэн даахыг харна.
- **FedEx (Business district, өгөгдлийн зам)** — нэмсэн ном хүснэгт → тоолуур → хайлт → устгах → API-ийн GET хүртэл ямар замаар явж, хаана нь өгөгдөл өөрчлөгдөх/алдагдахыг мөшгинө.

## Хугацаа

60 минутын нэг session. Апп өгөгдлөө санах ойд хадгалдаг тул согог бүрийг `node app.js`-ийг шинээр асаасан (анхны 3 ном) төлөвөөс дахин шалгана.
