## Хэсэг E: Дүгнэлт (debrief)

Хамгийн үр дүнтэй нь **Supermodel** аялал байв: хуудсыг нээгээд л BUG-01 (тоолуур +1), BUG-02 (он таслалтай), BUG-03 (ногоон Устгах), BUG-04 (латин «x») дөрвөн согог, мөн BUG-10-ын «Хуучин хувилбар» линк анзаарагдсан. **Saboteur** (curl) аялал хоёрдугаарт — BUG-11 (буруу JSON-д 200 OK)-ийг зөвхөн энэ аялал илрүүлэх боломжтой байсан бөгөөд BUG-08 (давхардал), BUG-09 (хайлт), BUG-10 (500)-ийг ч API түвшинд анх олж, дараа нь UI-аар баталсан. **Couch Potato** нэг удаагийн «хоосон Нэмэx» даралтаар BUG-05-ийг, **Antisocial** аялал BUG-07 (он 2500/abc), BUG-12 (урт гарчиг), BUG-13 (давхар escape)-ыг, **FedEx** аялал устгах замыг мөшгихөд BUG-06 (буруу мессеж)-г олсон.

Charter-аас гадуур санамсаргүй олдсон зүйл бол BUG-13 — XSS шалгахаар `<b>` оруулсан чинь script ажиллаагүй ч `&` тэмдэгт буруу харагдаж байгааг анзаарсан; мөн ном нэмсний дараа форм цэвэрлэгдэхгүй, байхгүй id-г `DELETE` хийхэд 200 OK буцдаг, устгахаас өмнө баталгаажуулах асуулт байхгүй гэдэг нь тайлан болоогүй ажиглалт болж үлдэв. Шалгагдаагүй үлдсэн нь: олон хэрэглэгч зэрэг ажиллах, `PUT`/засварлах үйлдэл байгаа эсэх, гарын товчлуураар (Enter, Tab) ажиллах хүртээмж, мобайл өргөн, маш олон (1000+) ном ачаалах гүйцэтгэл — эдгээр нь дараагийн session-ий charter болно.

Лаб 1-ийн Playwright автомат тест хүлээгдэх утгыг тодорхой бичсэн бол BUG-01 (тоолуурын текст vs мөрийн тоо), BUG-02 (`1971` текст), BUG-05/07/08 (нэмсний дараах мөрийн тоо), BUG-06 (мессежийн текст), BUG-09 (хайлтын үр дүн), BUG-10 (статус код), BUG-11 (API статус) — ихэнхийг нь барих байсан; BUG-04 ч `getByRole('button', {name: 'Нэмэх'})` олдохгүй тул санамсаргүй баригдана. Харин BUG-03 (товчны өнгө), BUG-12 (хүснэгтийн байршил эвдрэх), BUG-13 (`&amp;` харагдах) нь тестийн assertion-д урьдчилан бичигдээгүй л бол зөвхөн хүний нүдээр, эсвэл visual regression тестээр олдох согогууд. Дүгнэвэл автомат тест «бидний мэдэж байгаа» дүрмийг баталгаажуулдаг бол exploratory тест «бодоогүй байсан» асуудлыг илрүүлдэг тул хоёулаа хэрэгтэй.
